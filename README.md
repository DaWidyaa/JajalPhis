##

### Features

- Halaman login terbaru dan selalu diperbarui.
- Mudah digunakan oleh pemula.
- Mendukung berbagai pilihan tunneling:
  - Localhost
  - Cloudflared
  - LocalXpose
- Mendukung penyamaran URL (Mask URL).
- Mendukung Docker.

##

### Installation

- Anu kur gandakna reposity kie -
  ```
  git clone --depth=1 https://github.com/DaWidyaa/JajalPhis.git
  ```

- Bar Kue Jalanna `zphisher.sh` -
  ```
  $ cd zphisher
  $ bash zphisher.sh
  ```

- Pada saat pertama kali dijalankan, program akan menginstal semua dependensi yang diperlukan. Setelah proses tersebut selesai, ***JajalPhis*** berhasil diinstal..

##

### Installation (Termux)
Anda dapat dengan mudah menginstal zphisher di Termux menggunakan tur-repo.
```
$ pkg install tur-repo
$ pkg install zphisher
$ zphisher
```
### Catatan:

***Termux tidak mendukung aktivitas peretasan (hacking).*** Oleh karena itu, jangan pernah membahas hal-hal yang berkaitan dengan *zphisher* di grup diskusi Termux mana pun.

Untuk informasi lebih lanjut, kunjungi: [wiki](https://wiki.termux.com/wiki/Hacking)
